xm xero-mirror Xero → MySQL

把 Xero 會計資料鏡射到你的 MySQL

xero-mirror 是一支常駐的 Go 服務，把 Xero Accounting 的發票、聯絡人與設定資料單向同步到本地 MySQL。 整個過程只讀取 Xero，不會寫回任何資料；來源端永遠是唯一的事實來源。

Go 1.24 MySQL 8.4 Apache-2.0 單向同步

主要特性

四種觸發同步

支援 cron 排程、cursor 增量、指定月份的月度回補，以及 Xero webhook 觸發的批次同步，四條路徑共用同一套同步核心。

冪等 upsert

以 Xero ID 為鍵寫入，同一批資料重跑結果相同；中斷後可從 cursor 續跑，不會產生重複資料列。

憑證加密

OAuth2 token 以 AES-256-GCM 加密後存入 MySQL，refresh 採單飛輪換，新 access 與 refresh token 同一交易寫回。

軟刪除鏡射

Xero 以 DELETE 或 ARCHIVED 標記的資料照實保留狀態，不因 API 未回傳而刪除本地列，完整鏡射來源端現況。

快速開始

先複製 .env.example 為 .env 並填入 Xero 憑證，再啟動資料庫與服務。 

docker compose up -d
./xero-mirror.exe auth
./xero-mirror.exe serve
xero-mirror 本服務僅供內網部署；專案文件見 repo 的 doc/，程式碼遵循 AGENTS.md。
